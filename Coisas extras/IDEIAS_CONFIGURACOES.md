# ⚙️ Ideias de Configurações (ValiantShop)

Este documento reúne 30 ideias de opções customizáveis para a tela de configurações, com foco em imersão Pokémon, utilidade na loja e integração com mods como Cobblemon. *(Nenhum sistema de XP, pass ou missões está incluído).*

### 🎨 Personalização Visual
4. **Mini-Sprite de Cursor:** Substituir o cursor normal pelo sprite pixelizado do Pokémon favorito.

### 🛒 Padrões da Loja Valiant
20. **Limpeza Automática do Carrinho:** Limpar o carrinho automaticamente caso uma janela seja acidentalmente fechada após X horas.

### 🎮 Integração e Imersão Cobblemon
25. **Classe de Treinador:** Um título cosmético ("Bug Catcher", "Ace Trainer", "Breeder") que aparece do lado do seu nome.
